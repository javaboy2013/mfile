# mfile 打包安装指南

> 本项目「自测 → 打包 → 本地安装 → 用户验收」的完整流程与踩坑。适用于 macOS（arm64）。

## 一、标准流程（每次功能交付）

```bash
# 1. 全量自测（单测 <1s + E2E ~1.5min 后台跑）
npm run test:all

# 2. 打包 + 覆盖安装（一键）
npm run deploy
# 等价于：electron-builder --mac && rm -rf /Applications/mfile.app && cp -R dist/mac-arm64/mfile.app /Applications/

# 3. 启动验收
open /Applications/mfile.app
```

**重要：安装前先杀掉正在运行的实例**（`deploy` 未含，手动执行更稳）：

```bash
ps aux | grep -iE "mfile.app|dist/Electron" | grep -v grep | awk '{print $2}' | xargs kill
```

原因有二：
- dev 实例与正式版窗口同位置同大小，重叠会触发 macOS 遮挡暂停渲染，曾导致误判「应用卡死」（其实是被盖住的窗口冻结）
- 替换正在运行的 .app 偶发文件占用

## 二、产物说明（dist/）

| 文件 | 用途 |
|---|---|
| `mac-arm64/mfile.app` | 直接可运行的 app（本地安装拷这个） |
| `mfile-<版本>-arm64.dmg` | 分发安装包（拖拽安装） |
| `mfile-<版本>-arm64-mac.zip` | **自动更新通道**（latest-mac.yml 指向它） |
| `latest-mac.yml` | 更新清单（版本号 + 文件 + 哈希） |
| `*.blockmap` | 增量下载用（electron-updater 差量更新） |

## 三、配置解读（electron-builder.yml）

```yaml
appId: com.vincent.mfile        # Bundle ID（升级安装需保持一致）
productName: mfile
directories.buildResources: build   # 图标等资源目录（build/icon.icns）
files:                          # 只打进 asar 的内容
  - electron/**/*               # 主进程 + preload
  - ui/**/*                     # 渲染层（原生 ES modules，无构建步骤）
  - package.json                # 生产依赖（electron-updater）由 builder 智能打入
mac.target: [dmg, zip]          # zip 是 updater 通道必需
publish: github javaboy2013/mfile  # electron-updater 的更新源
```

## 四、对外发布（GitHub Releases）

```bash
# 1. bump 版本（package.json 的 version）
# 2. 提交并打 tag
git tag v0.2.x && git push --tags
# 3. CI（.github/workflows/release.yml）自动：
#    npm install → npm test → electron-builder --mac --publish always
#    → 产物 + latest-mac.yml 挂到 Release
# 4. 已装用户点 ⟳ 或启动静默检查即可收到更新
```

## 五、已知坑

| 坑 | 处理 |
|---|---|
| **dmg 打包失败 "hdiutil couldn't unmount disk4"** | 上次打包的卷未卸净。`hdiutil detach /dev/disk4 -force` 后重跑 |
| **"skipped macOS code signing" 警告** | 未配 Apple 开发者证书，属正常。正式分发需 Developer ID + 公证 |
| **首次打开被 Gatekeeper 拦（未签名）** | 系统设置 → 隐私与安全性 → 仍要打开；或右键 app → 打开 |
| **更新检查 404 / 跳过** | 未打 Release 或 dev 模式（not packed）时 updater 自动跳过——⟳ 显示「已是最新版本」属预期 |
| **Electron 二进制下载慢** | `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install` |
| **版本号忘了 bump** | 更新通道按版本号判断，不打 tag 不 bump = 用户收不到更新 |

## 六、验收清单（安装后快速过一遍）

1. 启动：窗口出现即完整加载页 → 动画 → 主界面（无白屏/闪变）
2. 菜单栏：中文菜单 + 快捷键（⌘⌫ 删除、⇧⌘H 回主目录）
3. 列表：框选/⌘点多选、右键菜单分组与二级
4. 解压冲突三选一（重命名规则 x → x 2）
5. 主题六套 + ⟳ 检查更新
