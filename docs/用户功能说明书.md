# mfile 功能说明书

面向使用者的操作说明。安装与开发请参考 [README.md](README.md)。

mfile 是一款 macOS 文件管理器，可替代访达（Finder）完成日常文件浏览与管理。界面分为五个区域：

```
┌──────────────────────────────────────────┐
│  顶栏：导航按钮 / 新建 / 排序 / 隐藏文件 / 主题  │
├────────┬─────────────────────────────────┤
│        │  面包屑路径栏                      │
│  侧栏   ├─────────────────────────────────┤
│  快速   │  过滤栏：即时过滤 + 标签            │
│  访问   ├─────────────────────────────────┤
│        │  文件列表                          │
│        │                                 │
├────────┴─────────────────────────────────┤
│  状态栏：当前目录 · 选中数量 · 项目总数          │
└──────────────────────────────────────────┘
```

---

## 1. 浏览与导航

### 侧栏快速访问

| 项目 | 跳转位置 |
|---|---|
| 主目录 | `/Users/<你>`（`$HOME`） |
| 应用程序 | `/Applications` |
| 文稿 | `~/Documents` |
| 下载 | `~/Downloads` |
| 图片 | `~/Pictures` |
| 音乐 | `~/Music` |
| 影片 | `~/Movies` |
| 桌面 | `~/Desktop` |
| 根目录 | `/` |
| 废纸篓 | `~/.Trash`（可浏览，目录内右键可清空） |

### 面包屑路径栏
- 显示当前路径的每一级层级，**点击任意层级直接跳转**到该目录。
- 最后一级高亮显示为当前位置。
- 按 `⌘L` 或点击路径栏可**手动输入完整路径**跳转（支持 `/` 开头的绝对路径），回车确认，Esc 取消。路径不存在会提示。

### 后退与上一级
- 后退：返回上一个访问过的目录（历史栈）。
- 上一级：跳到当前目录的父目录（面包屑也可实现同样效果）。

### 打开文件与目录
- **双击**目录 → 进入该目录。
- **双击**文件 → 用系统默认应用打开（等同访达双击）。
- 单击行 → 选中；`⌘`/`Ctrl` + 单击 → 多选；`⇧` + 单击 → 范围选。
- `Enter` → 打开当前唯一选中的项目。

### 符号链接
指向目录的软链接会正确识别为目录（双击可进入），损坏的软链接按文件处理。

## 2. 文件与文件夹操作

### 新建
- **新建文件夹**：顶栏按钮或右键菜单，在当前目录创建。
- **新建文件**：顶栏按钮或右键菜单，创建空文件。**同名已存在会报错**，不会静默覆盖。

### 重命名
- 选中后按 `⌘D`（或 `F2`），弹窗输入新名称，回车确认。
- 等同访达的回车重命名，但快捷键为 `⌘D`。

### 删除（移到废纸篓）
- 选中后按 `Delete` / `Backspace`，或右键菜单"删除"。
- 弹出**确认框**，文件/文件夹将**移到废纸篓**（与访达一致，可从废纸篓找回）。

### 废纸篓
- **侧栏点击"废纸篓"** 进入 `~/.Trash` 浏览，可正常复制/查看。
- 在废纸篓目录内**右键 → "清空废纸篓"**，确认后永久删除全部内容（不可恢复）。

### 压缩与解压
- **压缩**：选中一个或多个项目，右键 → "压缩为 ZIP"。
  - 单选取文件主名（`dirA` → `dirA.zip`），多选生成 `归档.zip`。
  - 目录递归压缩，保留内部结构。
  - 当前目录已有同名 zip 会报错，不覆盖。
- **解压**：选中**单个** `.zip` 文件，右键 → "解压到当前目录"。
  - 解压前检查同名冲突，有冲突直接报错不覆盖。
  - 自动拒绝含路径穿越（`../`）或绝对路径的恶意 zip。
  - 仅支持 zip 格式（其他压缩格式如 rar/7z 需用其他工具）。

### 复制 / 剪切 / 粘贴
| 操作 | 快捷键 |
|---|---|
| 复制 | `⌘C` |
| 剪切 | `⌘X` |
| 粘贴 | `⌘V` |

- 复制/剪切可多选，粘贴到目标目录后执行。
- **目录会递归复制**（包括全部子层内容）。
- 剪切在 mfile 中是"移动"语义（同盘 rename，跨盘为复制后删除原文件）。实际实现为 `move_entries`（同 `fs::rename`），**跨卷移动可能失败**。
- **目标目录已有同名文件会报错**，不会覆盖。需先删除或重命名目标侧同名项。

### 在终端中打开
右键菜单 → "在终端中打开"，用 **Terminal.app** 在该目录打开新终端窗口。需已安装系统终端。

### 计算目录大小
选中目录后，右键菜单 / 顶栏触发 `dir_size`，**递归统计**该目录全部文件的总大小，结果显示在界面。
- 大目录（几万文件）会耗时数秒到数十秒，期间界面可继续操作。
- 统计是同步遍历，结果为字节数（界面已格式化为 KB/MB/GB）。

## 3. 排序、过滤与搜索

### 排序
顶栏下拉切换，目录始终置顶：

| 排序方式 | 说明 |
|---|---|
| 名称 | 默认，字母序（不区分大小写） |
| 大小 | 按文件体积 |
| 时间 | 按修改时间 |
| 类型 | 按扩展名 |

### 即时过滤
顶栏过滤框输入文字，**当前目录**内文件名实时过滤（不进入子目录）。清空输入即恢复。

### 标签过滤
过滤框中输入以**空格分隔的多个关键词**即视为多个标签，文件名**同时包含全部关键词**才会显示（AND 语义）。例如输入 `png 2024` 只显示名字同时含 "png" 和 "2024" 的文件。

### 深度搜索
1. 按 `⌘F` 打开搜索面板，自动聚焦输入框。
2. 输入关键词，回车执行。
3. 从**当前目录递归搜索**全部子层（跳过隐藏文件和 `.` 开头目录）。
4. 结果在新面板列出，点击可跳转所在位置。
5. `Esc` 关闭搜索面板。

**限制**：最多返回 **500 条**结果；总耗时上限 **10 秒**，超时返回已找到的部分。超大目录（如根目录）可能搜不全，建议进入更具体的目录再搜。

## 4. 隐藏文件

- 顶栏"隐藏文件"按钮切换显示/隐藏。
- 快捷键 `⌘.`（或访达同款 `⌘⇧.`，mfile 中两者等效，实际绑定为 `⌘.`）。
- 设置**持久化保存**，下次启动保持上次的选择。

## 5. 主题

顶栏主题菜单切换，6 套可选，选择持久化：

| 主题 | 风格 |
|---|---|
| dark | 深灰暗色（默认） |
| light | 纯净亮色 |
| sepia | 羊皮纸护眼暖色 |
| ocean | 深海蓝 |
| purple | 暗紫 |
| glass | 毛玻璃（按 Apple HIG：玻璃只给控件层，内容区不透明） |

## 6. 右键菜单

在文件列表任意位置右键：

**有选中项时：**
- 复制路径（单个选中项的完整路径，写入系统剪贴板）
- 复制文件名
- 删除（红色警示）
- 复制
- 剪切

**任何时候：**
- 在终端中打开
- 新建文件夹
- 新建文件
- 清空废纸篓（仅当当前目录是废纸篓时显示，红色警示）

**右键未选中的行时**，会先自动选中该行再弹出菜单。

## 7. 快捷键总表

| 快捷键 | 功能 |
|---|---|
| `⌘F` | 打开深度搜索面板 |
| `⌘L` | 手动输入路径跳转 |
| `⌘C` / `⌘X` / `⌘V` | 复制 / 剪切 / 粘贴 |
| `⌘A` | 全选（当前过滤后的可见项） |
| `⌘D` | 重命名选中项 |
| `⌘.` | 显示 / 隐藏隐藏文件 |
| `⌘E` | 触发测试错误（验证错误提示可复制，日常无用途） |
| `Enter` | 打开唯一选中的项目 |
| `Delete` / `Backspace` | 删除选中项（带确认） |
| `Esc` | 关闭搜索面板 |

---

## 8. 状态栏与提示

- **状态栏**：显示当前目录、选中数量、项目总数。
- **Toast 通知**：操作成功（如"已复制"）绿色提示，错误红色提示，几秒后自动消失。
- **复制回执**：复制路径 / 文件名 / 错误信息后，触发按钮会短暂显示"已复制"作为确认。

---

## 9. 注意事项

1. **删除默认进废纸篓**，可找回；但"清空废纸篓"是永久删除，不可撤销。
2. **粘贴/移动/解压遇到同名冲突直接报错**，不做"保留两者/覆盖/跳过"选择，需手动处理。
3. **深度搜索有 500 条 / 10 秒双重上限**，搜不全时缩小搜索范围。
4. **目录大小计算是同步递归遍历**，超大目录会卡顿等待，属正常现象。
5. **跨盘剪切**本质是 `rename`，跨卷时可能失败，建议用"复制 + 手动删除"替代。
6. 应用图标与打包配置位于 `src-tauri/icons/` 与 `tauri.conf.json`，修改方式见 README。
