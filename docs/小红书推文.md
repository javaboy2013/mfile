## 正文（≤1000字）

说真的，Mac 最劝退 Windows 用户的就是 Finder。

我的崩溃清单，你中了几条👇

😭 **「我的电脑呢？」**
双击「此电脑」看所有盘的动作刻在 DNA 里，Mac 打开 Finder 一片空白，文件去哪了全靠回忆

😭 **「D盘呢？我的文件放哪？」**
Mac 只有「用户目录」，下载、文稿、桌面混在一起，想分个「软件盘」「资料盘」完全没有入口

😭 **「右键怎么是空的？」**
在空白处右键，什么都没有。新建文件夹还得绕路操作，Windows 用户直接懵

😭 **「隐藏文件找不到」**
想看 .git、.env 这种配置文件？Windows 勾一下「显示隐藏项目」就行，Mac 的快捷键 ⌘⇧. 根本没人告诉你

😭 **「复制个文件名都费劲」**
Windows 右键重命名就能复制名字，Mac 右键只有「拷贝」——想发个文件名给同事、贴个完整路径到终端，全是手动打字

😭 **「删个东西还要学习」**
废纸篓没有「清空」按钮思维，总担心误删整个目录

我也是被折磨了一个月，最后一怒之下自己写了个文件管理器：**mfile**

打开就是「我的电脑」，D盘 E盘 F盘 安排得明明白白——
📦 软件盘、资料盘、工作盘，各归各位
🖱 空白处右键直接新建文件夹，手感回来了
📋 右键「复制文件名」「复制完整路径」，发消息/进终端直接粘
👁 「隐藏文件」按钮一键切换，.git/.env 直接现形
⚡ 侧栏一键直达用户/下载/桌面，不再层层点
🗑 废纸篓一键清空，还带删除保护防手滑
🔍 ⌘F 过滤 + 深度搜索，找文件不用翻半天

不改变你的 Windows 习惯，而是让 Mac 顺应你。

开源免费，M 系列芯片 Mac 直接下载就用。

GitHub 搜 **mfile**，链接评论区置顶👇

如果觉得好用，送小红书一颗心❤️，GitHub 再来一颗星⭐，双倍鼓励，作者更新更有动力！
